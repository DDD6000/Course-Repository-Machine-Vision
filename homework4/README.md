# 作业4：书本倾斜校正（把倾斜的书转正）

## 算法

与作业3 完全同一套思路（区域 → 外接矩形 → 仿射旋转 → 裁剪），**唯一区别是"怎么把目标分割出来"**：

- 作业3 是白底扫描件 → 固定阈值取"非白"；
- 本题背景是**米黄色木纹桌面**、书本是**蓝色**，灰度上两者亮度接近，用灰度阈值分不开，所以在 **Lab 色彩空间的 b\* 通道**（黄-蓝轴）上做 Otsu 分割：b\* 大 = 偏黄（木桌），b\* 小 = 偏蓝（书本），再乘一个"亮度 > 60"去掉书本投影的阴影。

完整流程：

1. 读入原图（960×1280）
2. 彩色转灰度（仅用于后续平滑与亮度约束）
3. 高斯平滑 5×5
4. **颜色分割**：`Lab.b*` 上 Otsu 反相阈值 + `gray > 60`
5. **形态学 + 最大连通域**：15×15 闭运算补封面上花纹造成的断口、开运算去噪，保留最大连通域（书本本体）
6. **`findContours` + `minAreaRect`**：最小外接矩形，尺寸 848×623，旋转角 71.60°；折叠到 (-45°, 45°] 得需旋转角 **-18.40°**
7. **迭代旋转修正**：`warpAffine`（画布扩大、空白填白）→ 复测残余角 → 直到 < 0.25°
8. **裁剪**：按旋转后已轴对齐的外接矩形裁掉背景，得到摆正的书

角度折叠的规则：直线没有方向性（0° 与 180° 是同一条），且"长边/短边"两族互相垂直只差 90°，所以统一把角度折叠到最近的坐标轴 `(-45°, 45°]`。矩形接近正方形时（如作业3 的 577×579），长宽哪条边当"长边"都不影响折叠后的结果。
