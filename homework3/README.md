# 作业3：图像倾斜校正（把倾斜的照片转正）

## 算法

把"倾斜的照片"当成一块**区域**来找姿态，流程与练习4（轮廓 + 最小外接矩形）一致，最后多一步仿射旋转：

1. 读入原图（628×628，照片放在纯白扫描底板上、整体倾斜）
2. 彩色转灰度
3. 高斯平滑 5×5
4. **前景分割**：底板是纯白（≈255），照片内容都比底板暗，故用固定阈值 `gray < 240` 取"非白"作为前景。此处不能用 Otsu——照片内部本身有很亮的区域（帽子高光），Otsu 会把它们判成背景；同时把最外圈 4 像素扫描黑边清零，否则黑边会把外接矩形拉成水平
5. **形态学 + 最大连通域**：15×15 闭运算补上照片内部的高光空洞、开运算去噪，只保留面积最大的连通域（照片本体）
6. **`findContours` + `minAreaRect`**：得到最小外接矩形，取其旋转角并折叠到 (-45°, 45°] 即得需要旋转的角度（直线无方向性，水平/竖直两族只差 90°，所以统一折叠到最近的坐标轴）
7. **迭代旋转修正**：`warpAffine` 旋转（画布自动扩大，照片不会被裁掉，空白填白）→ 在新图上重新测量 → 若残余角仍 > 0.25° 再修正一次，最多 3 次
8. **裁剪**：旋转后外接矩形已与坐标轴对齐，取它的外接框裁掉四周空白，得到摆正的照片

## 文件

- `deskew.cpp`：源程序（OpenCV C++）
- `image.png`：原始图片
- `step1_src.png`：原图
- `step2_gray.png`：灰度图
- `step3_blur.png`：高斯平滑
- `step4_mask.png`：前景分割（非白=目标）
- `step5_morph.png`：形态学 + 最大连通域
- `step6_minrect.png`：轮廓（绿）+ 最小外接矩形（黄）+ 测出的角度
- `step7_rotated.png`：旋转校正后的整幅图
- `step8_cropped.png`：裁剪后的最终摆正结果

## 编译运行

```
cl /EHsc /std:c++17 /I "D:\OpenCV\opencv\build\include" deskew.cpp ^
   /link /LIBPATH:"D:\OpenCV\opencv\build\x64\vc16\lib" opencv_world4120.lib
deskew.exe image.png
```
