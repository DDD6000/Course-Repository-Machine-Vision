# 课堂练习：完整圆孔计数

## 算法

基于**灰度阈值 + 连通域分析 + 形状特征过滤**的计数方法（孔洞为暗目标、金属表面为亮背景）：

1. 裁掉四周扫描黑边（黑边会与贴边孔洞连成一体，干扰判断）
2. 彩色转灰度
3. 高斯平滑，抑制金属纹理与反光噪声
4. Otsu 自动阈值 + 反相二值化，孔洞变成白色前景
5. 形态学闭运算补缺口、开运算去噪点
6. 连通域标记，一个孔洞对应一个连通域
7. 三重过滤，只保留"完整的圆"：
   - 贴到图像边界的目标 → 剔除（被切断的不完整大孔、左侧不规则孔）
   - 圆度 `4πA/P² < 0.75` 的目标 → 剔除（非圆形的暗区、细长划痕）
   - 面积小于候选面积中位数 25% 的目标 → 剔除（碎屑噪点）
8. 统计剩余连通域个数即为完整圆孔数量

结果图中绿色框为计入的圆孔，青色框为被判为非目标/不完整的区域。
